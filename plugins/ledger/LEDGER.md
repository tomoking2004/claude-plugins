# ledger の正典

`.ledger/` の形と書き込みの決まりは，本書だけが定める．/ledger:update-ledger と /ledger:tidy-ledger は実行時に本書を読む．会話の始まりに Claude へ渡る決まりは，本書の要約である．

## 受け持つもの

- **CLAUDE.md の仲間**：プロジェクトの根（git の根．git の外では作業ディレクトリ）から下にある `CLAUDE.md`（各階）・`.claude/CLAUDE.md`・`.claude/rules/` の下の `.md`・`CLAUDE.local.md`．私用は `CLAUDE.local.md` が持つ．`~/.claude/` の下のものは，プロジェクトをまたぐので含めない．
- **境目**：`.ledger/` はプロジェクトの中身を，CLAUDE.md の仲間は作業の仕方を持つ．
  - 中身：何を作り，何が分かったか——目的・仕様・設計の決定・仮説・評価の基準・外の制約・調べて分かったこと・未決の問い．
  - 作業の仕方：どう作業するか——コマンド・書き方の約束・道具と環境・作業フォルダとファイルの扱い・してはいけない操作．
  - 判定：その記述が答えるのが「どう作業するか」なら作業の仕方，「何を作り，何が分かったか」なら中身．どちらとも言えなければ，案とは別の問いとして利用者に問う．
- **自動メモリ**：Claude 自身の覚え書きで，このマシンにだけある．プロジェクトの中身は ledger が持つので，自動メモリへ書かない．
- **境目をまたいで移すとき**：/ledger:tidy-ledger が，認められた移す案に限って，CLAUDE.md の仲間を書き換える．
  - 両側を一度に書き換える——片側だけでは，同じ事柄が二か所に残るか，どこからも失われる．ただし移す先に同じ事柄が既にあれば，移す先は変えず，元を消すだけにする．
  - 移す先の書式に合わせる．CLAUDE.md の仲間へは，題と出所の行を外し，そのファイルの書き方で書く．`.ledger/` へは，「項の書式」で書く．
  - CLAUDE.md の仲間への移す先は，同じ類の指示が既にあるファイルとし，無ければプロジェクトの根の `CLAUDE.md` とする．`.claude/rules/` の下のファイルの前置き（`paths` など）は変えない．
  - 私用は私用へだけ移す——`CLAUDE.local.md` と `local/` の間で移し，追跡される側へは出さない（「私用と秘密」）．追跡される側から追跡される側へ移す記述に個人の事情が混ざっていれば，「私用と秘密」で事情と決定を分ける．
  - 移す案の差分のほかは，CLAUDE.md の仲間を書き換えない．`~/.claude/` の下と自動メモリは書き換えない．

## 置き場

- **探し方**：作業ディレクトリからプロジェクトの根まで上へたどり，最初に見つかった `.ledger/` を使う．git の外で作業ディレクトリだけを見るのは，上の階にある別のプロジェクトの記録を取り違えて使わないためである．
- **作るとき**：初めて書く項が承認されたときに，プロジェクトの根に作る．同時に，中身が `local/` の1行だけの `.ledger/.gitignore` を作る．その場所と `.gitignore` は案に含めて示す．利用者のプロジェクトの `.gitignore` は書き換えない．作ったら，`git check-ignore` で `local/` の下のパスが外れることを確かめる（git の外なら確かめない）．
- **追跡**：`.ledger/` は git で追跡する前提で置き，コードと一緒に別のマシン・ブランチ・共同作業者へ渡る．git から外れるのは `local/` だけである．

## フォルダの形

```text
.ledger/
  general.md    どの仕事にも効く項
  <主題>.md     特定の仕事にだけ効く項．主題ごとに1ファイル
  local/        私用．同じ形を持つ
  .gitignore    中身は `local/` の1行
```

- **項**：一つの項は，一つの事柄（後の仕事を縛る決定・事実・未決の問いのどれか）を持つ．
- **いまの姿**：記録は，いまの姿だけを持つ．前の文面は，追跡される記録では git の履歴が持つ．`local/` は前の文面を持たない．
- **置き分け**：項は，効く範囲で置き分ける．`general.md` は会話の始まりに全文が渡るので，どの仕事にも効く項だけを置く．特定の仕事にだけ効く項は `<主題>.md` に置く．`<主題>.md` は題と字数だけが渡り，その仕事に触れるときに開かれる．
- **分けるとき**：分けるのは，開かずに済むファイルが増えるときだけ．同じ仕事でいつも一緒に開く二つの主題は，一つに畳む．
- **ファイルとフォルダ**：書く項のあるファイルだけを作る．空のファイルと空のフォルダは置かない——消す・移す案で項が尽きるファイルとフォルダは，その案に除くことを添えて示す．
- **主題の名前**：`<主題>` は，小文字の英数字とハイフンで書く（`auth`・`evaluation`）．`general` は主題に使わない．

## 項の書式

```markdown
## <題>

<文面．1〜3文>

出所：<出所>（YYYY-MM-DD）
```

- **題**：`local/` を含む `.ledger/` の全体で一意にする．会話の始まりには題の一覧が渡るので，題だけで中身の見当がつくように書く．
- **文面**：決定の当てはめに理由が要るなら，理由を文面に一句で添える．理由が個人の事情なら，追跡される側では添えない（「私用と秘密」）．
- **出所**：`<出所>` には次のどれかを書く．日付は書いた日で，環境から取る．
  - 「利用者の発言」．
  - 「`<パス>` を確かめた」「`<コマンド>` の出力を確かめた」：実物で確かめた事実．
  - 「`<パス>` から移した」：CLAUDE.md の仲間から移した項．人が書いたものとして，利用者の発言と同じに扱う．
- **未決**：利用者が「未決として残して」と言ったときだけ，題の頭に「未決：」を付けて残す．
- **退けた案**：後の仕事を縛るときだけ，項として書く（「X は採らない」と，その理由）．
- **改める・消す・移す**：項を書き換え，除き，あるいは文面と出所を変えずに別のファイルへ移す（境目をまたいで移すときは「境目をまたいで移すとき」に従う）．前の文面は案で示すが，書き残さない．

## 書く条件

- **四つの条件**：次の四つを満たすものだけを書く．
  - プロジェクトの中身であること（「判定」による）．
  - 利用者が述べたこと，または実物（ファイル・コマンドの出力）で確かめたこと．
  - 後の仕事を縛ること．
  - コード・差分・CLAUDE.md の仲間・自動メモリから読めないこと．
- **書かないもの**：次のものは書かず，それぞれの置き場に任せる．
  - 作業の仕方：CLAUDE.md の仲間が持つ（私的なものは `CLAUDE.local.md`）．番号を振った案には入れず，置き先と文面を別に添える——書くかは利用者が決め，/ledger:update-ledger は書かない．
  - 一度きりの作業指示と，作業の進み具合：会話とタスクの道具が持つ．
  - 利用者自身の好みと，プロジェクトをまたぐ事柄：自動メモリと `~/.claude/CLAUDE.md` が持つ．
  - 推し量ったこと：確かめるか，利用者に問う．
  - 弱い項（後の仕事を縛るか分からないもの）：書かない方が，読む量と誤りがともに減る．
- **格上げしない**：発言を約束や合意へ格上げしない．利用者がまだ決めていないことは，「未決」に当たるときを除いて書かない．
- **私用と秘密**：
  - 個人の事情（誰がいつ，なぜ抜けるかなど）は，追跡される側へ書かない．このプロジェクトの後の仕事を縛るときだけ，`local/` へ書く案にする．
  - 事情から決まったプロジェクトの決定（日取りの制約など）は，事情にも理由にも触れない文面で，追跡される側へ書く案にする——決定は共同作業者の仕事も縛るからである．
  - 利用者が私用と言った事柄は，決定でも `local/` へ書く案にする．`CLAUDE.local.md` と `local/` に置かれた記述は，私用と言った事柄に当たる．
  - パスワード・鍵・トークンは `local/` にも書かず，在処（環境変数の名前など）だけを書く．
- **秘密の検索**：書いた記述を，大文字と小文字を区別せずに `password`・`token`・`secret`・`BEGIN` で，また20字以上続く英数字の列で検索する．当たった行は一件ずつ読み，在処の名前なら残し，値なら除く．

## 案の示し方

- **時**：記録に値することがあった返答の末尾に，まとめて示す．作業の途中では示さない．エージェントとして起こされた側は示さず，記録に値することを報告に書く——記録するかは，利用者と話す会話が決める．
- **形**：案に番号を振り，案ごとに次のものを並べる．
  - 操作：足す・改める・消す・移すのどれか．
  - 書き先：`.ledger/` からのパス．CLAUDE.md の仲間なら，プロジェクトの根からのパス．移す案では，移す先．
  - 文面：書く形のまま．消す案は持たない．
  - 出所：「項の書式」の出所の行のまま．
  - 理由：どの仕事を縛るかを一行で．改める・消す・移す案では，そうする理由．
  - 前の文面：改める・消す・移す案だけ．元の書き先も添える．
- **照合**：示す前に，同じ事柄を，`.ledger/` の全ファイル（`local/` を含む）・CLAUDE.md の仲間・自動メモリから検索する．既に書かれた事柄は案にしない．食い違う項が `.ledger/` にあれば，その案は「改める」とし，前の文面と並べる．利用者が取り消したことと，実物を読んで既存の項との食い違いに気づいたことも，消す案か改める案にする．
- **問い方**：承認は，平文の提案へのチャットの返信で受ける——選択式ダイアログは提案の表示を妨げるため使わない（承認でなく選ぶだけの問いは選択式でよい）．

## 承認

- **認めた案だけ**：利用者が番号か「全部」で明示して認めた案だけを，示した文面のまま書く．
- **見せた内容だけ**：承認が覆うのは見せた内容だけである——提案の後に内容を変えたら（但し書き1つでも）示して改めて問い，見せていない他所の変更を含めない．修正指示は反映して再提案，意図の割れる箇所は問う．
- **示し直さない**：答えの無い案と断られた案は，同じ会話で再び示さない．利用者は /ledger:update-ledger で，いつでも呼び直せる．
- **省かない**：承認を省く設定は持たない．書いた記録は以後の会話が読んで従うので，一度の誤りが後まで残る．

## 会話の始まりに渡るもの

`.ledger/` の直下か `local/` に空でない記録（`.md`）があれば，会話の始まりと，コンテキストの圧縮のあとに，次のものが Claude へ渡る．

- `general.md` の全文．
- `<主題>.md` の題の一覧と字数．
- `local/` の同じもの．私用の印を付ける．
- 本書の要約（受け持つもの・置き分け・項の書式・書く条件・案の示し方・承認）．

**上限**：渡る量は，記録の在処を告げる一文と本書の要約までを含む全体で，4,000字までとする．超えるなら，`general.md`（`local/` のものも）を題の一覧に落とし，全文で渡したときの全体の字数と，/ledger:tidy-ledger での整理を勧める文を添える——超えたのが一つのファイルでなく全体だと分かるように．このとき Claude は，どの仕事の前にも，在る `general.md` と `local/general.md` を開く．それでも超えるなら，ファイルの名前と字数だけに落とし，なお超える分はファイルの数だけを書く．
