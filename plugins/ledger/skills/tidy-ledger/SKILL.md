対象：作業ディレクトリから上へたどって見つかる `.ledger/` の全ファイル（`local/` を含む）と，プロジェクトの中にある CLAUDE.md の仲間．

まず [LEDGER.md](../../LEDGER.md) を読む．

## 手順

1. **探す**：同書の「探し方」で `.ledger/` を探し，同書の「CLAUDE.md の仲間」を探す．どちらも無ければ，整理するものが無いと答えて終わる．
2. **測る**：ファイルごとの字数と，会話の始まりに渡る量（同書の「会話の始まりに渡るもの」の全体）を測り，同書の「上限」と並べる．渡る文のうち，記録のほかの部分（在処を告げる文・見出し・要約）は mod（[register.ts](../../hooks/register.ts) の `compose` と `note`）が組み立てる．字数は，バイトでなく文字の数で数える．
3. **突き合わせる**：各項を実物と突き合わせる．出所が「確かめた」の項は，そのパスを読み直すか，そのコマンドを走らせ直す．出所が利用者の発言か「移した」の項は，実物と食い違うときだけ挙げる——どちらが正しいかは利用者が決める．
4. **見比べる**：同じ事柄を持つ二つの項，食い違う二つの項，自動メモリと重なる項，同書の「書く条件」を満たさなくなった項（済んだ作業・失効した前提），同書の「置き分け」に合わない項（`general.md` にあって特定の仕事にだけ効く項，`<主題>.md` にあってどの仕事にも効く項）を探す．
5. **境目を見る**：CLAUDE.md の仲間を通して読み，プロジェクトの中身に当たる記述を探す．`.ledger/` の項から，作業の仕方に当たるものを探す．判定は同書の「判定」の問いによる．どちらとも言えない記述は，移す案にせず問いとして挙げる．同じ事柄が両側にあれば，境目の正しい側に残し，他方から移す案にする（同書の「境目をまたいで移すとき」により，元を消すだけになる）．追跡される側の記述に個人の事情が混ざっていれば，同書の「私用と秘密」で事情と決定を分ける案にする．
6. **分け方を決める**：同書の「分けるとき」に照らし，分けるか畳むかを決める．分ける案と畳む案には，前後の渡る量と，仕事ごとに開くファイルの数と字数を並べ，同書の「分けるとき」に当たるものだけを案にする．
7. **示す**：手順3〜6で見つけたものを，同書の「案の示し方」で案にする．自動メモリと重なる項は案にせず，手順10で挙げる．各案の理由には，見つけた手順と測った数を添える．分ける案と畳む案は，移す項ごとの案に分け，その一群の前に手順6で並べた数を置く．境目をまたぐ移す案は，元の文面・移す先の文面・両側の書き先を並べる．`.ledger/` が無いまま移す案があれば，同書の「作るとき」の場所に作る案を先頭に置く．案が無ければ，測った数と通した手順を報告して終わる．
8. **当てる**：認められた案だけを，同書の「項の書式」と「境目をまたいで移すとき」で当てる．`.ledger/` が無いまま移すなら，同書の「作るとき」に従って作る．
9. **走査する**：当てた差分に「固有の走査」を全件通す．その差分が承認された案と違うなら，当てた箇所を案のとおりに直して走査に戻る．案そのものに欠けがあれば，当てた箇所を元に戻し（秘密の値はただちに除く），直した案を示して改めて問う．
10. **報告する**：当てた案と見送った案，当てる前後の渡る量，分けたファイルと畳んだファイルごとに手順6で並べた数を報告する．自動メモリと重なる項は，報告に挙げる．

## 固有の走査

- **承認との一致**：当てた差分を，`.ledger/` と CLAUDE.md の仲間の両側で，承認された案と一件ずつ並べ，案に無い変更が無いかを確かめる．
- **題の行方**：当てる前後で，`.ledger/` の題の集合を並べ，消えた題と移った題がどれも承認された案に当たるかを確かめる．
- **境目の対**：境目をまたいで移した記述ごとに，元から消え，移す先にあるかを並べる．
- **私用の保持**：`CLAUDE.local.md` と `local/` から移した記述が，追跡される側に出ていないかを確かめる．`local/` の外へ当てた記述に，個人の事情が無いかを読む．
- **出所の保持**：出所を改める案の項を除き，残した項と `.ledger/` の中で移した項が元の出所の行を持ち，CLAUDE.md の仲間から移した項が「`<パス>` から移した」の出所を持つかを確かめる．
- **秘密**：当てた差分で書いた記述（改めた項・畳んだ項・移した記述）に，同書の「秘密の検索」を通す．検索語と当たった件数と判定を報告する．
- **外れるか**：手順8で `.ledger/` を作ったなら，同書の「作るとき」の確かめを通す．
- **渡る量**：当てた後の渡る量を測り，上限と並べる．上限を超えて始めた整理なら，下回ったことを数で示す．
- **分けた根拠**：分けたファイルと畳んだファイルごとに，手順6で並べた数が報告にあるかを確かめる．

## 制約

- コードは書き換えない．CLAUDE.md の仲間・`~/.claude/` の下・自動メモリは，同書の「境目をまたいで移すとき」のとおりに扱う．
- 項を書き足さない．整理の途中で書くに値する事柄に気づいたら，/ledger:update-ledger の案として報告に挙げる．境目をまたいで移すのは，書き足しに当たらない．
