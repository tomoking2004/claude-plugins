# キツネが働くアニメーション

Claude（本体）とそのサブエージェント（分身）が処理している間，ドット絵のキツネが働く様子をパネルに映す．実用性は求めず，待ち時間を楽しく過ごすためのものである．

fox が持つのは，キツネの絵と，キツネを theater に加える数行のモジュールである．絵は，ベースキャラ（何も持たずに座っているキツネの待機アニメーション）に，役割ごとの小道具と動きを重ねて描く．絵を画面へ出す仕組み（役割の切り替え・並べ方・パネルの描画）は theater が持ち，その決まりは theater の DESIGN.md が定める．本書は，キツネの絵と動きの決まり，個体ごとの差，絵の書き出しと確かめ方，残っている作業を定める．絵を直すときは本書を先に読み，直したら本書も合わせる．

## 構成

| 置き場 | 中身 |
| --- | --- |
| `.claude-plugin/plugin.json` | プラグインのマニフェスト．theater を依存先に宣言する |
| `.claude-plugin/icon.png` | プラグインの一覧に出るアイコン（目を開いた本体のベースキャラ）．書き出しの道具が作るので，手で直さない |
| `preview.gif` | README のプレビュー（本体の働く6つの役割）．書き出しの道具が作るので，手で直さない |
| `bin/fox-claude-code-only` | プラグインを Claude Code 専用にする印 |
| `art/fox_main.gif`・`art/fox_sub.gif` | ベースキャラ（本体・分身） |
| `art/draw.py` | 役割ごとの絵を，ベースキャラに重ねて描く．書き出す絵（`sprites()`），個体ごとに置き換える色（`VARIANTS`），アイコンにする絵（`ICON`）を，書き出しの道具へ渡す |
| `sprites/` | パネルが流すアニメーション（SVG．役割ごと，本体は眠気の段階ごとに1枚）と，絵の一覧（`index.json`）．書き出しの道具が作るので，手で直さない |
| `hooks/hooks.json` | Claude Code に読み込ませるモジュール（`register.ts`）を名指す |
| `hooks/register.ts` | セッションの開始時に，キツネを theater に加える |

書き出しの道具は，theater の `tools/build.py` である．絵を直したら，リポジトリの最上位で `python plugins/theater/tools/build.py plugins/fox <確かめ用.gif>` を走らせる（Pillow が要る）．`sprites/` とアイコンと README のプレビューが作り直され，全ての絵を黒背景に並べた確かめ用のプレビューが，渡したパスにできる．絵を変えない直しの確かめ方は，「確かめ方」が定める．

確かめ用のプレビューは，1段に6つの役割が並ぶ（考える・調べる・書く・実行する・見守る・呼ぶの順）．1段目は本体，2段目は分身，3〜5段目は本体の眠気の段階1〜3，6段目は本体・分身の「眠る」である．役割と眠気は「役割とデザイン」が定める．

Claude のチャットで絵を直すなら，`art/` の中身，本書，書き出しの道具，theater の DESIGN.md（色数などの絵の決まりを定める）を添付し，本書を読んで絵を直すよう頼む．あわせて，次を頼む．

- 添付した `art/` の中身を `art` という名前のディレクトリに置き，その親のディレクトリを書き出しの道具へ渡して走らせる
- 描き終えたら，確かめ用のプレビューを作って見せる
- 本書も絵に合わせる
- `art/` の中で変えたファイルと，本書を返す

返ってきた本書は元の場所に，ほかのファイルは `art/` に置き，手元で書き出しの道具を走らせる．

## ベースキャラ（確定）

- `fox_main.gif`（本体）・`fox_sub.gif`（分身）：64×64ドットを4倍に拡大（256×256），背景は透過，無限ループ，1周4.8秒（100msを1刻みとして48刻み．刻みは0から数える）．2つは同じ時刻に同じ姿勢で，違いは葉っぱだけ
- 見た目：耳先と足先が黒，尻尾の先が白，頬が赤く，口はω．分身はおでこに葉っぱを乗せる
- 待機アニメーション：目を開け閉めし（視線も左右に動く），体が1ドット沈み，尻尾が揺れ，左右の耳が別々の時刻にぴくっと動く．分身は，頭が揺れると葉っぱが少し遅れてついてくる
- 前足：ベースキャラには描かない（前足のないほうが美しいため）．前足を使う役割では，役割の絵が描く
- 目：開いた目は5×6ドットの焦げ茶（下側を明るく，左上に光）．大きな黒い目は不気味に見えるため，目を小さくし，柔らかい色にしている
- 縁取り：内側の線（耳の付け根・あご・体と後ろ足の境など）は毛の濃い色で柔らかく，外側の輪郭と口は濃い茶色．黒い耳先・足先の外側の縁も茶色にして，暗い画面の黒い背景に溶けないようにしている

ベースキャラを直すときは，これらの決まりを崩さない．ベースキャラの GIF を保存する道具は置いていない．保存するときは，色を減らさない（全ての刻みの色をそのまま並べたパレットに，1ドットずつ引き当てる．Pillow の quantize は近い色を取り違える）．直したあとも，「構成」の手順で書き出しの道具を走らせる．

`art/draw.py` は，ベースキャラに次を前提にする．

- GIF のコマの長さが100msの倍数で，計48刻みである
- 刻み0（目を閉じている）と刻み16は同じ姿勢で，目だけが違う
- 体が沈む刻み（`DY`）と，目を描く枠（`EYE_BOXES`）が，いまのベースキャラと同じである

## 役割とデザイン（確定）

### 本体と分身

- 昔話の「化け狐」にならい，葉っぱを「分身のしるし」とする．葉っぱの意味はこれだけにし，葉っぱの形と色は変えない
- 本体（メインの Claude）：葉っぱなし．これを標準の姿とする
- 分身（サブエージェント）：葉っぱあり．耳先・足先の黒は本体のまま残す（本体と分身の違いは葉っぱだけにするため）

### 役割ごとの絵

役割は，働く6つと，働き終えた「眠る」の7つである．どのツールでどの役割になるかは，theater が決める．

| 役割 | ポーズ・小道具・動き |
| --- | --- |
| 考える | ベースキャラの待機アニメーション（そのまま） |
| 調べる | 布張りの本を自分へ向けて開いて読む（見えるのは表紙・裏表紙と背．表紙の縁に押し型，背に金の帯，上からページの小口がのぞく）．本がゆっくり上下し，視線が行を追う．ページをめくるときは本を大きく下げ，ページが弧を描いて返る |
| 書く | 前に木の座卓（木目のある天板，手前の縁，脚）．天板に和紙を寝かせ，白い羽ペンを紙の左から右へ大きく走らせ，字の線が伸びる．頭も羽ペンを追って傾く．ときどき腕を大きく回して，コルク栓のガラスのインク壺に浸し，新しい紙の行頭で構える |
| 実行する | 前に木の座卓と，その上の銀色のノートパソコン（実物に近い縦横比．見えるのはふたの外側と蝶番，キーボード側の縁．座卓に影が落ちる．ふたに肉球のシール）．必死にカタカタ打つ：前足がふたの上へ交互に跳ね上がり（下りた前足はキーボードの上でふたに隠れる），打つたびに頭が揺れる（汗は出さない）．ときどき両方の前足をそろえて構え，Enter を押し込む（腕を大きく伸ばす動きはしない） |
| 見守る | 分身の働きを，目を閉じて，お茶を飲みながら待つ．湯呑みは灰緑の釉薬の焼き物で，線の模様と素焼きの高台があり，口縁から緑茶が見える．両方の前足で両脇から包むように持つ．湯気がゆらゆら高く昇り，ときどき湯呑みを口まで持ち上げて一口飲む |
| 呼ぶ | こちらを向いて，胸の前で前足を小さく振って合図する（跳ねる・首をかしげるなどの大きな動きは不自然なのでしない）．相手に呼びかける役割なので，こちらを向くのが自然 |
| 眠る | 頭を垂れて眠る．ゆっくり息をして頭が上下する |

### 本体の眠気

本体のコンテキストの量を表す眠気は，働く役割の絵に重ねる．目はベースキャラの閉じた目に戻すだけで，新しく描かない．段階の境目は theater が決める．

| 段階 | 様子 |
| --- | --- |
| 0 | 眠気なし |
| 1 | まぶたが重く，長いまばたきが増える |
| 2 | 1に加えて，ときどき大きなあくびをする．口が見えるよう，本は大きく下げ，羽ペンは止めて脇へどける．パソコンは下げられないので，打つのを止めるだけにする（口の大半はふたの陰に隠れる） |
| 3 | 目を閉じて頭がゆっくり下がり（船をこぐ），ハッと起きて，あくびをする．このあくびは一口飲む時刻に重なるので，湯呑みは口まで持ち上げない |

まぶたの重さとあくびは，役割の絵が描く．「考える」はベースキャラの絵をそのまま使うので，眠気が表れるのは，段階3で頭が下がることだけである．「見守る」はもともと目を閉じているので，段階1の絵は段階0と同じである．コンテキストの量が減って段階が0へ戻れば，すっきり目覚める．

### 止まる姿

パネルが絵を止めて描くときは，書き出した絵の刻み0の姿が映る（どのときに止めるかは，theater の DESIGN.md の「絵の決まり」が述べる）．ベースキャラの刻み0は目を閉じているので，書き出す絵は，描く刻みの4（`art/draw.py` の `START`）から始めて1周させる．本書と `art/draw.py` が言う刻みは，描く刻み（ベースキャラの刻み）である．書き出した絵の刻みは，そこから4つ前へずれる．

描く刻み4では，どの役割も，眠気のどの段階でも，まばたき・あくび・船をこぐ動きに当たらず，体も沈んでいない．止まる姿は次のとおりである．

| 役割 | 止まる姿 |
| --- | --- |
| 考える | 目を開けて，前を向いて座る（本体はアイコンと同じ姿） |
| 調べる | 目を開けて，上げた本を，正面の視線で読む |
| 書く | 目を開けて，頭をまっすぐにし，1行目の途中に羽ペンを置く |
| 実行する | 目を開けて，片方の前足をふたの上へ跳ね上げる |
| 見守る | 目を閉じて，下ろした湯呑みを持つ．湯気が昇る |
| 呼ぶ | 目を開けて，こちらを向き，前足を胸の前に上げる |
| 眠る | 目を閉じて，頭を垂れる |

`START` を変えるときは，全ての役割と眠気の段階で，その刻みが止まる姿にふさわしいことを確かめる．

### 絵の大きさ

VS Code では，theater が，並べる絵の大きさ（SVG の文字数）の合計を25万字に収め，収まらないキツネを省く（theater の DESIGN.md の「表示」が定める）．最も大きいのは「書く」の絵で，本体が5.1万〜7.8万字，分身が5.6万字である．本体と，書く分身3体までは，眠気のどの段階でも，その絵のまま並ぶ．動きを足すと絵は大きくなるので，絵を直したら，`sprites/` の「書く」の絵の文字数を見て，本体の最も大きい絵と分身の絵3枚の合計が25万字に収まることを確かめる．

### 見た目の決まり

- 一貫性：どの役割も，ベースキャラの待機アニメーション（尻尾の揺れ・耳のぴくっ・体の沈み）をそのまま使う．役割が変えるのは，目の開け閉めと視線，前足，頭の傾き，小道具だけ
- 小道具：実物らしく描く（素材の色，光と陰，縁や継ぎ目などの細部）．キツネの横ではなく，前に置く．キツネが実際に使う向きに置き，見る人へ見せる向きにはしない（例：パソコンはふたの外側が見え，画面は見えない）
- 目：ベースキャラ自身の目を使う．閉じた目（刻み0），開いた目（刻み16．刻み0と同じ姿勢のまま目だけ開いている）とも，新しく描かない．開いた目は瞳・光のドットをすべて写し，形も高さもベースキャラどおりにする（視線は左右に1ドット動かすだけ）．作業中はときどきまばたきする
- 動き：作業の動き（タイピングなど）は，頑張っている感じが伝わるよう大きくする．ただし，合図などの身ぶり（呼ぶ）は控えめにする．汗や画面の光などの効果は足さない
- 葉っぱ（分身だけ）：遅れてついてくる動きは「考える」だけ．ほかの役割では頭に固定する．小道具などにも葉っぱの形を使わない（しるしの意味が薄れるため）

## 個体ごとの差

同じ役割でも，分身ごとに動きと色が少しずつ変わる．変える仕組みは theater が持ち，fox は変える値を決める．デザインそのものは変えない．

| 値 | 状態 |
| --- | --- |
| 動きの位相 | 実装済み（theater が，どのキャラクターにも付ける） |
| 小道具の色 | 本の表紙だけ実装済み．元の色と，色相を回した5通りの，計6通りを `art/draw.py` の `COVER_HUES` が持つ．表紙の色は本だけに使う（`sprites()` が確かめる）．シールは未実装 |
| まばたきの間隔 | 未実装．絵に焼き込まれているので，変えるには間隔ごとの絵が要る |
| 尻尾を振る周期 | 未実装．ベースキャラの動きなので，変えるには周期ごとのベースキャラが要る |

## 確かめ方

リポジトリの最上位で `claude plugin validate plugins/fox` を走らせ，プラグインの読み込みを確かめる．パネルの描画と状態の決まりの検査は，theater が持つ．

絵を変えない `art/draw.py` の直し（描き方の整理）では，直す前と後に書き出しの道具を走らせ，全ての書き出し（`sprites/`・アイコン・2つのプレビュー）が1バイトも変わらないことを確かめる．直す前の書き出しは，比べるために別の場所へ写しておく．

`START` だけを変える直しでは，書き出しのバイトは変わる．直す前と後の絵を読み戻し（読み戻し方は theater の DESIGN.md の「確かめ方」が述べる），全ての絵の全ての刻みが，ずらした刻みの数を除いて1ドットも違わないことを確かめる．
