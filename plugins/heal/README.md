# heal

スキルの失敗・批判の根本原因を診断して直し，定義全体の重複と食い違いも解消して再発を防ぐ保守スキル群．

## 導入

手順はマーケットプレイスの README（リポジトリ最上位の README.md）が定める．

- **対応先**：Claude Code と Claude．チャットでは，/heal:heal-skill の診断と修正案までを行える——定義の書き換えと /heal:heal-canon は，リポジトリのある環境で行う．
- **依存先**：なし

## 使い方

- **失敗したスキルを直す**：/heal:heal-skill が原因を診断し，定義を更新して再発を防ぐ．どのプラグインのスキルにも使える．
- **定義全体を手入れする**：/heal:heal-canon が定義全体を見直し，溜まった重複と食い違いを解消する．
