# ops

ローカル環境の運用として，長時間走るプログラムの起動・監視・状況照会・完了報告と，Claude Code 自身が残す痕跡の掃除を担うスキル群．

## 導入

手順はマーケットプレイスの README（リポジトリ最上位の README.md）が定める．

- **対応先**：Claude Code 専用．手元のマシンを扱うので，Claude には追加できないようにしてある．
- **依存先**：heal

## 使い方

- **長いプログラムを走らせる**：数十秒を超えて走るもの（学習・評価・サーバ等）を頼むと，スキル名の指定が無くても /ops:run-job が働き，起動から完了報告までを担う．数十秒で終わる実行（テスト・ビルド等）は素のまま走らせる．
- **走っているものの様子を見る**：/ops:check-job が調べて答える．
- **Claude Code の履歴を消す**：/ops:clean-traces が，このマシンに溜まった履歴・痕跡を掃除する．何を消すかを列挙し，承認を得てから消す．ログイン・設定・導入済みプラグイン・自動メモリは残る．
