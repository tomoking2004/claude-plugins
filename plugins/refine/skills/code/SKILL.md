対象：指定された範囲のコード；無指定ならプロジェクト全コード（生成物のみ除く；`.gitignore` 対象も走査し，私的なメモ等は変えてよいかを先に問う）．

まず [BEAUTY.md](../../BEAUTY.md) を読み，美の6条と走査の規律に従う．

## 媒体の正典

- **Python**：PEP 8・PEP 20・PEP 257．公開 API は型ヒントと Docstring を持つ．
- **その他の言語**：その言語の公式スタイルガイド；無ければ既存ファイルの多数派．

## 固有の走査

- **名前鎖**：公開名・改名は定義→呼び出し→引数→直列化キー→テンプレート→Docstring まで追跡し，全箇所を一致させる．
- **識別子族**：同義語群・動詞族・接頭辞/接尾辞の規約をコード全域で列挙し，揺れを潰す．
- **列挙値**：enum・状態・設定値は取りうる値を一箇所に定義し，判定の軸を一つにする（定義の違う値を同じ列に混ぜない）．

## 制約

公開挙動は保つ——変更のたびにテスト・実行で確かめ，バグ修正で変わるなら明示する．構造を移す変更は，中身が変わらないことを差分（正規化して同一）で示す．git は読み込みのみ．スクリプトで一括編集するときは，編集箇所を一意な文字列で指定し，想定する一致件数をスクリプトに検査させ，結果を読み直して完了とする．判断の割れる箇所は推測せず問う．問い方：調べて届くことは調べ尽くし，ユーザーにしか分からないことだけを最初にまとめて問う．問いには調べた範囲・対象の原文・問う理由・答えで変わることを書き，未確認の前提で選ばせない．対象が一通りに読めるなら問わずにその読みで進め，採った読みを報告に1行載せる．ユーザーの発話が問いの形なら，依頼と読まず問いとして答える．
