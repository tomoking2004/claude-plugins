対象：指定された範囲のコード；無指定ならプロジェクト全コード（生成物のみ除く；`.gitignore` 対象も走査し，私的なメモ等は変更前に問う）．

まず [BEAUTY.md](../../BEAUTY.md) を読み，美の6条と走査の規律に従う．

## 媒体の正典

- **Python**：PEP 8・PEP 20・PEP 257．公開 API は型ヒントと Docstring を持つ．
- **その他の言語**：その言語の公式スタイルガイド；無ければ既存ファイルの多数派．

## 固有の走査

- **名前鎖**：公開名・改名は定義→呼び出し→引数→直列化キー→テンプレート→Docstring まで追跡し，全箇所を一致させる．
- **識別子族**：同義語群・動詞族・接頭辞/接尾辞の規約をコード全域で列挙し，揺れを潰す．

## 制約

公開挙動は保つ——変更のたびにテスト・実行で確かめ，バグ修正で変わるなら明示する．git は読み込みのみ．判断の割れる箇所は推測せず問う．

## 失敗時

/heal:skill を呼ぶ．
