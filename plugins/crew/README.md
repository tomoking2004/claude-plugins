# crew

大きな仕事を独りで抱え込まないよう，エージェントへ任せる部分と自分に残す部分を見分け，分担を適切な時にだけ促す．

## 導入

手順はマーケットプレイスの README（リポジトリ最上位の README.md）が定める．

- **対応先**：Claude Code 専用．エージェントへ仕事を分けるのが役目で，知らせは Claude Code の拡張の仕組み（mod）が届けるので，Claude には追加できないようにしてある．
- **依存先**：heal

## 使い方

- **大きな仕事を頼む時**：多数の指摘の処置や全体の仕上げのように，独立した部分を幾つも含む仕事は，/crew:divide-work が分担して進める．仕事を部分に割り，任せる側と残す側を見分け，依頼文（目的・既に分かったこと・範囲・返してほしい形）を書き，戻った結果の決め手だけを確かめる．小さな仕事と，互いに絡む直しは分担しない．スキル名を指定しないと，Claude はこのスキルを選ばずに独りで進めることがあるので，確実に使わせるなら名指す．
- **独りで読み続けている時**：Claude がエージェントに何も任せないまま，一つの依頼の中で読み・調べのツール（Read・Grep・Glob・WebFetch・WebSearch）の使用とコマンドの実行が合わせて40回に達したとする．そのとき crew は Claude に，残りを任せるかこのまま続けるかを見分けるよう，1回だけ知らせる．読みはコマンド（`cat` など）でも済まされるので，コマンドの実行も数える．ファイルを書くツールは数えない．
- **エージェントを多く起こした時**：一つの依頼の中で起こしたエージェントが8体に達すると，crew は Claude に，費用が数に比例して増えることと，この先は本当に要る分だけを起こすことを，1回だけ知らせる．作業を止めて利用者に問うようには求めない——始める前に8体以上を見積もった時の問いは，/crew:divide-work が定める．

どちらの知らせも Claude にだけ届き，画面には出ない．crew はツールの呼び出しを止めることも，書き換えることもない．任せるかどうかは Claude が決める．
