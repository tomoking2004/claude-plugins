# capstone

仕上げ・記録・公開を通じて，プロジェクトを完成という頂へ載せきる工程スキル群．

## 導入

手順はマーケットプレイスの README（リポジトリ最上位の README.md）が定める．

- **対応先**：Claude Code 専用．手元のリポジトリを扱うので，Claude には追加できないようにしてある．
- **依存先**：refine・heal

## 使い方

完成までの工程の順に使う．

1. /capstone:refine-project で全体を仕上げる．範囲を媒体に分解し，refine の媒体スキル（媒体ごとの仕上げのスキル）へ委譲する．媒体が一つだけなら，その媒体スキルを直接使う．
2. /capstone:commit-changes で変更を記録する．変更を意味の単位に分けてメッセージを提案し，承認を得てからコミットする（push はしない）．
3. /capstone:release-version で公開する．新しいバージョンを定めてタグと GitHub Release の文面を提案し，承認を得てから push まで行う．

## 開発

媒体をまたぐ仕上げ（/capstone:refine-project）は，特定の領域（大学の課題など）に固有の仕事でなく，完成の工程の一つである．そこで，領域のプラグインにも refine にも置かず，本プラグインに置く．refine には媒体スキルだけを持たせる．
