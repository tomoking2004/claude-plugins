---
name: refine
description: プロジェクト全体（または指定範囲）を最も美しい確定版へ仕上げる．範囲を媒体に分解して refine プラグインの各スキルへ委譲し，媒体間の継ぎ目を走査する．「プロジェクト全体を完璧にして」「全部洗練して」など，媒体をまたぐ仕上げを求められたときに使う．単一媒体の仕上げは refine プラグインの該当スキルを使う．
---

対象：指定された範囲；無指定ならプロジェクト全ファイル（生成物のみ除く；`.gitignore` 対象も走査し，私的なメモ等は変更前に問う）．

## 手順

1. **前提確認**：refine プラグインのスキル（/refine:code 等）が見えなければ，導入（`/plugin install refine@tomoking2004`）を促して中断する．
2. **分解**：対象を列挙し，媒体ごとに分類する．
3. **委譲**：各媒体を，導入済みスキルの description から対応する refine プラグインのスキルを選んで発動する——対応を列挙で固定しない（媒体スキルの増減に自動で追従させる）．対応スキルの無い媒体は報告する．
4. **継ぎ目の走査**：媒体スキルが済んだ後，媒体間にまたがる整合を走査する．
   - **名前鎖**：コードの公開名が文書（README・SKILL.md 等）でも一致していることを全件確かめる．
   - **用語統一**：同義語群・表記の規約を全媒体横断で列挙し，揺れを潰す．
   - **事実照合**：文書が語る数値・コマンド・手順をコード・実行結果と突き合わせる．
5. **確定**：走査を再実行しゼロを確認してから確定する．

## 制約

公開挙動は保つ（バグ修正で変わるなら明示）．git は読み込みのみ．判断の割れる箇所は推測せず問う．
